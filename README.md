# Tamil Transliteration Automation Testing

This project automates the testing of the Tamil Transliteration web application using Playwright.

## Prerequisites
- Node.js installed (v14 or higher)
- Visual Studio Code (optional, but recommended)

## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/asjsolo/Tamil-Transliteration-Test.git

2.Navigate to the project folder:

	cd Tamil-Transliteration-Test

3.install dependencies:

	npm install playwright

4.To execute the automation script and generate results:

	node run_tests.js

OUTPUT:

*The script will launch a browser and execute 35 test cases.
*Results will be saved in a file named Test_Execution_Results.csv
